# Logistic Regression Classification Project

##  Project Overview
This project implements a complete Logistic Regression Classification workflow using Python and Scikit-learn. It covers data exploration, preprocessing, feature engineering, model training, evaluation, threshold tuning, and visualization techniques to build an effective binary classification model.

##  Features
- Data Loading and Exploration
- Data Cleaning and Preprocessing
- Feature Selection
- Train-Test Split
- Logistic Regression Model Training
- Accuracy Evaluation
- Confusion Matrix Analysis
- Classification Report
- ROC Curve and ROC-AUC Score
- Threshold Tuning
- Sigmoid Function Visualization
- Feature Importance Analysis

##  Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

##  Project Workflow

### 1. Data Exploration
- Display dataset preview
- Check dataset shape
- View data types
- Find missing values
- Generate statistical summary

### 2. Data Preprocessing
- Remove unnecessary columns
- Encode target variable
- Handle categorical features
- Scale numerical features

### 3. Model Training
- Split dataset into training and testing sets
- Train Logistic Regression model
- Generate predictions

### 4. Model Evaluation
- Accuracy Score
- Precision Score
- Recall Score
- F1-Score
- Confusion Matrix
- Classification Report
- ROC Curve
- ROC-AUC Score

### 5. Threshold Tuning
Evaluate model performance using different classification thresholds and compare:
- Precision
- Recall
- F1-Score

### 6. Visualization
- Sigmoid Function Curve
- Confusion Matrix Heatmap
- ROC Curve
- Feature Coefficient Plot

##  Results
The project demonstrates how Logistic Regression can be used for binary classification tasks. Various evaluation metrics and visualizations help assess model performance and identify opportunities for improvement.
